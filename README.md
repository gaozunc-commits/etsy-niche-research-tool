# Etsy Niche Research Tool

## About

Etsy Niche Research Tool is a personal research application developed to help me evaluate potential digital product niches by analyzing publicly available Etsy listing information.

The application uses Etsy's official API to retrieve listing information for market research purposes.

## Purpose

The purpose of this project is to support personal product research and help identify potential market opportunities before developing digital products.

## Features

- Search Etsy listings using multiple niche-related keywords.
- Estimate the number of matching search results.
- Analyze listing price ranges.
- Identify popular listings using favorite counts.
- Export retrieved listing information into CSV files.
- Generate research notes for comparing different product niches.

## How It Works

1. Enter a niche and its related search phrases.
2. The application sends search requests through Etsy's official API.
3. Retrieved listing information is analyzed.
4. Research results are saved locally for further analysis.

## Intended Users

This application is developed exclusively for personal use. It is not intended to be distributed, sold, or provided as a service to other users.

## Data Usage

The application retrieves publicly available listing information through Etsy's official API.

Retrieved information is used for personal market research and stored locally for analysis. The application does not modify Etsy listings, access private seller information, or retrieve sales data.

All API usage is subject to Etsy's applicable API terms and policies.

## Project Status

Currently under development and testing. API functionality will be tested against Etsy's live API after application approval.
